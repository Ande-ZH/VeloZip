- 64 项单元测试：Java 17 / Netty 4.1.68 和 Java 25 / Netty 4.2.7 两组均通过，无失败或跳过。
- 逐项结果：[Java 17 / Netty 4.1](tests/v1.0.0/java17-netty4.1.68.Final.json)、[Java 25 / Netty 4.2](tests/v1.0.0/java25-netty4.2.7.Final.json)。保留原始 JUnit 时间戳及报告哈希，明确标注可能使用 Gradle 缓存。

- `verifyArtifacts` 验证两份 jar 的 Java 17 字节码、版本一致性、后端 `api-version: 1.18`、Netty/NMS 排除和 YAML/Histogram 隔离。
- 传输协议仍为 1；测试统计以应用帧字节计数为准，不等同于 TCP 抓包或性能基准。

## 通过标准

每个激活用例要求客户端进入 PLAY 并持续连接至少 30 秒，连接期间两端各有一个激活连接；
断连后活动连接数归零、两端 TX/RX 计数相互一致、两个方向均有实际数据。
1.18 重连用例连续登录两次。

缺少后端插件时：可选模式保持原版连接，强制模式拒绝连接。
密钥不匹配时：后端明确发送 REFUSE，代理显示拒绝原因并回退。
代理禁用时：不发生激活。负面用例要求至少 15 秒保持连接，强制拒绝用例除外。
任何 vanilla 回退异常、计数泄漏或测试子进程未退出均不视为通过。

## 测试隔离与复现

使用回环随机端口、新建平坦世界、随机转发密钥及独立插件配置。
后端最大堆 1200 MiB、代理 512 MiB，两端使用 `-XX:ActiveProcessorCount=2`；
世界生成参数显式指定地层，避免不同版本对空 flat 配置的回退。
控制台诊断等待完整响应，最长 15 秒；不依赖固定 1.5 秒采样。

参照 `scripts/e2e-fixture.example.json` 提供本地官方服务端和 JDK 路径：

```bash
./gradlew build :velozip-itest:writeBotClasspaths
npm ci --prefix scripts --ignore-scripts
node scripts/e2e-matrix.mjs /absolute/path/to/fixture.json
E2E_EVIDENCE_DATE=2026-09-11 node scripts/e2e-evidence.mjs /absolute/path/to/build/e2e-matrix-XXXXXX
```

测试不会复用世界或运行中的服务。可选 seed 仅复制官方运行库/缓存。
运行测试会给隔离实例写入 `eula=true`，需已接受 Minecraft EULA。

## 初轮测试暴露的问题

- 旧版 Bukkit 未收到通道注册时，静默丢弃 REFUSE。代理现已在 REQ 前发送 `minecraft:register`。
- 代理回退原来重新添加已移除的 Netty 解码器，触发不可共享限制。现改为保留实例和缓冲并进入 vanilla-only 模式。
- 固定采样延迟在 JVM 预热时读不到完整诊断，已改成等待完整输出。
- 初轮存在服务器启动超时；最终用显式平坦世界参数和限制处理器数量的顺序矩阵重新验证。

数据中保留 5 次初轮失败；早期按旧标准通过但收发计数未完全收敛的尝试也保留原记录。
`superseded: true` 表示已被后续重跑替代，只将每个用例最后一次、满足完整断连/计数检查的结果计入最终通过数。
仅最终成品包对应的通过用例用于确认本版兼容性。
本报告不保证未测试的构建、第三方网络插件组合或长期高负载行为。
